# ICE

## Facts

- Project being tested, includes a gateway server, frontend, and backend services
- The project is described in the documentation.
- A platform for non-technical users to build cloud infrastructure from simple blocks
- The ICE project includes a desktop application that embeds the full gateway and services within Electron.
- The project uses Docker, Prisma migrations, and various development scripts.
- The ICE desktop app is part of the ICE project.
- Fully functional infrastructure design and deployment — no login, no billing, no OAuth.
- Integrates Claude (Anthropic) as an AI assistant for modifying canvas infrastructure via natural language.
